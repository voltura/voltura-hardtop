# Voltura HardTop 1.0.3

Press **Ctrl+F** in the window picker to focus search and select the current filter so you can replace it.

**One-time manual upgrade for existing users.** HardTop's update-signing key has changed. If you have v1.0.2 or earlier, download the matching Windows installer below and run it once. Use the lightweight installer if you previously installed the lightweight version. Once v1.0.3 is installed, automatic updates can verify future releases again. If you use the portable edition, download and extract the new ZIP as usual.
