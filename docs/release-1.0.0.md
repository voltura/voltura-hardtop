# Voltura HardTop 1.0.0

A new Windows companion based on original HardTop, with a separate application identity and settings.

- Search windows and pin them above the rest; the picker stays reachable above pinned windows.
- Capture global shortcuts directly, with conflict checks that preserve the previous binding.
- Choose 21 languages, light/dark/system appearance, window opacity and startup with Windows.
- Restore HardTop's own pin changes on graceful exit, with confirmation for user-requested exit.
- Install per-user with a self-contained NSIS installer or run the portable ZIP.
- Installed copies download signed, verified updates and ask before installation.

Windows x64. No account or analytics. MIT, copyright © Voltura AB. Original HardTop remains unchanged.

Release signing uses a local self-signed certificate with timestamping. Windows may show publisher or SmartScreen warnings; the signature does not create public publisher trust.
