# Privacy

No account, analytics, telemetry or cloud synchronization is used. Window titles and process names are read locally to display the picker and are not uploaded or logged. Settings remain on your computer.

Installed copies contact GitHub for update metadata at startup and every 24 hours. Automatic downloads can be disabled in Preferences. GitHub receives ordinary HTTPS connection information. Portable copies contact GitHub only when you select Check for updates, and use the download page for manual updates.

Opening the website, support, SourceForge or sponsor links opens your browser and is subject to those services' policies. Local release signing contacts the configured timestamp service; normal app operation does not.
